# docs — 實驗方法論與結果彙整

## 方法論

1. **固定規格**：每題用 SDD 流程產生一份 `spec.md`，所有模型共用（見各題 `spec/`）。
2. **隔離實作**：各模型在 `experiments/<model>/` 獨立實作，不互相參考。
3. **統一評測**：對相同 `benchmark/testcase/` 執行，以相同 `verifier` 判定正確性，記錄最佳化指標。
4. **三項數據**：通過/失敗、最佳化指標、時間或開發回合數。

## RQ

- **RQ1**：SDD 流程 vs. 直接實作（以 `reference/` 人類解為對照）對品質/效率的影響。
- **RQ2**：相同規格下不同模型的正確率與最佳化品質差異。
